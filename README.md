# Comparative Analysis of Recommender Systems (MovieTweetings)
1. Download ratings.dat and movies.dat from https://github.com/sidooms/MovieTweetings (latest/) into ../data/
2. pip install -r requirements.txt
3. python run_experiments.py   (~5 min, CPU only; writes results/)
Seed fixed (42). Library: recsys_lib.py. Report generator: build_report.js (node, docx).
